 FixMyCity – Smart City Issue Reporting Mobile Application

 📖 Overview

FixMyCity is an Android mobile application developed to improve communication between citizens and local authorities. The application provides a simple and efficient platform for reporting public issues such as road damages, garbage problems, drainage blockages, and broken streetlights.

The project supports **United Nations Sustainable Development Goal (SDG) 11 – Sustainable Cities and Communities** by helping create cleaner, safer, and more sustainable communities through digital issue management.

 💻 Installation Guide

 Prerequisites

Before running the project, ensure you have:

 Android Studio
 JDK 17 or above
 Android SDK
 Firebase Project Configuration

---

 Clone the Repository

```bash
git clone https://github.com/nawodyaweragoda-cyber/FixMyCity

cd FixMyCity
```

---

 Firebase Setup

1. Create a Firebase Project.
2. Enable Firebase Authentication.
3. Enable Cloud Firestore.
4. Enable Firebase Storage.
5. Download the google-services.json file.
6. Place the file inside the app directory.

---

 Run the Application

Open the project in Android Studio and click Run.

Or use:

```bash
./gradlew assembleDebug
```
